# nxapiのスマホ版

[日本語の詳細](README.ja.md) · [English](README.en.md) · [Android build guide](android/README.md)

Nintendo Switch Online用の非公式 `nxapi` を、PCなしでAndroid端末上に
セットアップして利用するためのフォークです。

Discord Rich Presence、SplatNet 3の追加情報、フレンド・ゲームサービス・
お知らせの表示に対応しています。詳細な使い方、ビルド手順、注意事項は上の
日本語または英語ドキュメントを確認してください。

> NintendoおよびDiscordとは提携していない非公式プロジェクトです。Nintendoの
> 非公式APIを使用するため、利用は自己責任でお願いします。
